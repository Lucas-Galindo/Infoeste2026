Alteração - Lucas Galindo - dia: 10/10/2026

O que foi alterado:
Tabela cliente (ids 1 a 42): corrigidos estado_id e cidade para que formem pares coerentes (ex.: Ribeirão Preto passa de Acre para São Paulo). 13 cidades foram trocadas por uma do estado já cadastrado, porque o estado correto não existe no catálogo (ex.: Wichita -> Chicago). Nenhuma outra tabela ou coluna foi alterada.

Porque:
Cidade e estado não combinavam. O trigger trg_cliente_valida_estado_pais só valida estado x país, então o erro passava despercebido e apareceria nos mapas do Power BI. Script idempotente e com transação (COMMIT só após conferência).

CODIGO:

USE agromaq_industrial;
SET SQL_SAFE_UPDATES = 0;

-- 1) PRÉ-CHECAGEM
SELECT c.id_cliente, c.nome, p.nome AS pais, e.nome AS estado, c.cidade
FROM cliente c
JOIN pais p ON p.id_pais = c.pais_id
LEFT JOIN estado_provincia e ON e.id_estado = c.estado_id
ORDER BY c.id_cliente;
